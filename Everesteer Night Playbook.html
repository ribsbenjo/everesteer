The round loop repeat all night

  1. Check last round's score next to the baseline's score.
  2. Pick one change: a new signal, a weight, a window length.
  3. Quick test on recent history. If it doesn't help there, drop it.
  4. Submit before the deadline. Always submit something.
  5. Write the change and its score in the team log.

One round is mostly luck. Judge an idea over 2–3 rounds before you trust it.

Blend signals

def z(df):  # rank across assets each day, centred on 0
    r = df.rank(axis=1, pct=True)
    return r - 0.5

signal = (1.0 * z(mom)
        + 0.5 * z(reversal)
        + 0.5 * z(lowvol))
forecast = signal.iloc[-1]   # latest row = this round

Averaging several weak signals beats one clever one on short, noisy rounds. If the score punishes overconfidence, shrink forecasts toward neutral (for example multiply by 0.5).

Mistakes that sink teams

  • Look-ahead bias: every feature needs .shift(1). Never use today's close to forecast today.
  • Overfitting: tuning 10 parameters on 3 months of data. Keep windows round (5, 20, 60).
  • Chasing one round: rewriting everything after one bad score.
  • Missing a deadline because code broke. Keep the last working version ready to submit.
  • Letting the LLM pick trades. Research shows that loses. Use AI to write and check code.
  • Wrong format: asset IDs or column names that don't match the template.
